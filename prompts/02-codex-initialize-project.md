# Prompt khởi tạo dự án

Hãy khởi tạo cấu trúc dự án Flask theo `AGENTS.md` và `docs/06-system-architecture.md`.

Phạm vi lần này:
- Tạo application factory.
- Cấu hình Flask-SQLAlchemy.
- Cấu hình Flask-Migrate.
- Cấu hình Flask-Login.
- Đọc biến môi trường.
- Kết nối SQL Server.
- Tạo route health check.
- Tạo test kiểm tra ứng dụng khởi động.

Chưa tạo model User.
Chưa làm đăng ký hoặc đăng nhập.
Không chạy DROP DATABASE.
Trước khi sửa code, hãy liệt kê các file dự kiến tạo.
