# --- chatbot: retrieval-augmented assistant (app/chatbot/) -------------------
# Kept to the smallest set that covers embeddings, chunking and vector search.
# No Chroma, FAISS, Redis or external vector database: the curated knowledge
# base is ~70 chunks and fits an in-process store.
#
# google-genai
#     Official Google Gen AI SDK. The only thing that talks to Gemini, and it
#     is reached exclusively through app/chatbot/providers/gemini.py, behind
#     the ChatModelProvider / EmbeddingProvider interfaces.
google-genai==2.23.0
# langchain-core
#     Used for Document, the Embeddings interface and InMemoryVectorStore.
#     Nothing else: no chains, no agents, no LangSmith tracing.
langchain-core==1.6.3
# langchain-text-splitters
#     MarkdownHeaderTextSplitter + RecursiveCharacterTextSplitter give the
#     heading-aware chunking the knowledge base relies on.
langchain-text-splitters==1.1.2
# numpy
#     Required at runtime by langchain-core's cosine_similarity, which
#     InMemoryVectorStore calls on every search. langchain-core does not
#     declare it, so similarity search raises ImportError without this pin.
numpy==2.5.3
